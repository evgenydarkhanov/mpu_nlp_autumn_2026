# Домашнее задание #01 (Attention. Transformer)

## Рефакторинг обучения BERT с чистого PyTorch на экосистему Hugging Face

На семинаре мы реализовали обучение модели `bert-base-uncased` для бинарной классификации отзывов IMDB с помощью `PyTorch`:
- написали свой класс `Dataset` и `DataLoader`;
- реализовали функции `train_one_epoch` и `eval_one_epoch` с ручным управлением `optimizer`, `scheduler`, `loss.backward()` и `torch.no_grad()`;
- вручную считали метрику `accuracy` и сохраняли чекпоинты после каждой эпохи.

**Задание**: переписать семинарский код обучения `bert-base-uncased` на датасете IMDB, заменив ручную работу с `PyTorch` на высокоуровневые инструменты библиотек `datasets`, `evaluate` и `transformers`.

В решении рекомендуется использовать стандартные абстракции экосистемы:
- `load_dataset`, `DatasetDict` и метод `.map()` для подготовки данных;
- `DataCollatorWithPadding` для батчинга;
- метрики и функции из `evaluate`;
- `TrainingArguments` и `Trainer` для обучения и сохранения чекпоинтов.

Список инструментов предоставлен для ориентирования и не является обязательным и исчерпывающим. Идея задания в том, чтобы перейти от ручной обработки к использованию готовых технологий.

**Формат сдачи**: файл Jupyter Notebook или ссылка на Google Colab с сохранёнными выводами ячеек. Значение `accuracy` на тестовой выборке должно быть не ниже 91.
